# Moon texture

`moon_color.jpg` is the LRO natural-colour global mosaic from NASA's
Scientific Visualization Studio, CGI Moon Kit
(https://svs.gsfc.nasa.gov/4720), file `lroc_color_2k.jpg`, resized from
2048x1024 to 1024x512. Equirectangular, centred on 0 degrees longitude, north
up. Built from Lunar Reconnaissance Orbiter Camera wide-angle data
(Arizona State University).

Credit: NASA's Scientific Visualization Studio.
